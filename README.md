# Texture Studio

繁體中文、本機運算的無縫貼圖與板材生成器。Python 3.11+、PySide6、OpenCV、NumPy、Pillow；無須外部 API、帳號或 API Key。

目前為可執行初版，不代表規格書 v1.0 全部完成驗收。核心演算法獨立於 UI，計算與圖片讀寫使用背景工作執行緒。取消在演算法步驟與板片之間生效，單次 FFT／解碼不能立即中斷。

## Windows 10／11

獨立版由 GitHub 的 Windows 建置流程產生：執行完整測試後，以 PyInstaller 打包成單一 `TextureStudio.exe`，再從隔離資料夾、移除外部 Python 路徑的情況下實際啟動，確認 GUI、原尺寸排列、筆刷、JPEG、BUMP 與法線輸出。通過後才將 EXE、ZIP、SHA-256 與 Windows 驗證報告附加至對應版本的 GitHub Release。

獨立版完整解壓縮後雙擊 `TextureStudio.exe`，不需安裝 Python，不開啟終端機。原始碼 ZIP 使用下列方式：

先將 ZIP **完整解壓縮**到一般資料夾，不可在壓縮檔檢視器內直接執行。首次使用需安裝 64-bit Python 3.12（3.11–3.13 也支援，包含 Python Launcher），執行一次：

```bat
setup_windows.bat
```

平常**雙擊 `TextureStudio.vbs`** 即可開啟，透過已安裝環境的 `pythonw.exe` 執行，不開啟終端機。`start_windows.bat` 也會轉交這個入口後退出。已使用前一版並完成安裝者可沿用環境，不需每次安裝。

Windows 腳本會將環境安裝至 `%USERPROFILE%\.texture-studio\venv`，避免 ZIP 解壓縮目錄過長，導致 PySide6 安裝失敗。不需系統管理員權限或修改 Windows 長路徑登錄設定。安裝、啟動、診斷與打包使用相同短路徑；也可設定 `TEXTURE_STUDIO_VENV` 使用自訂位置。先前安裝失敗的專案內 `.venv` 不會被刪除或沿用。

自行建置時，在 Windows 執行 `build_windows.bat`。它會安裝固定版本的建置套件、執行完整測試，以 `--onefile --windowed` 打包，檢查 PE x64／GUI 子系統並實際啟動單檔 EXE。結果位於 `%USERPROFILE%\.texture-studio\packaging\release`，可用 `TEXTURE_STUDIO_BUILD_ROOT` 指定其他輸出位置。建置失敗或獨立啟動驗證失敗，不會產生可發布的 release 檔案。

本版固定依賴支援 Python 3.11–3.13；Python 3.14 目前不支援。也可手動建立環境：

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m texture_studio
```

Linux 伺服器測試設定 `QT_QPA_PLATFORM=offscreen`。離屏模式不提供可互動桌面，實際操作需有圖形顯示環境。

### 啟動失敗或視窗閃退

先執行 `setup_windows.bat`，確認出現 `Setup completed`；再雙擊 `TextureStudio.vbs`。無終端機入口缺少環境時會顯示訊息，Python 啟動失敗則顯示錯誤紀錄位置。需要查看完整錯誤時執行 `diagnose_windows.bat`，診斷視窗會保留錯誤；安裝、診斷及 Python 紀錄分別位於 `logs/setup.log`、`logs/startup-console.log`、`logs/texture-studio.log`。

若短路徑環境使用不支援的 Python，先將 `%USERPROFILE%\.texture-studio\venv` 改名保留，安裝 64-bit Python 3.12，再重跑安裝腳本。腳本不會自動刪除既有環境。Windows 批次腳本仍須在 Windows 實機驗證；Linux 測試不能證明 Windows 安裝成功。

若使用舊 ZIP 遇到 Long Path 安裝錯誤，可在包含 `requirements.txt` 與 `launch.py` 的資料夾依序執行，不需重新下載：

```bat
py -3.12 -m venv "%USERPROFILE%\.texture-studio\venv"
"%USERPROFILE%\.texture-studio\venv\Scripts\python.exe" -m pip install -r requirements.txt
"%USERPROFILE%\.texture-studio\venv\Scripts\python.exe" launch.py
```

每一步成功後才進行下一步。`No module named cv2` 可能是前面套件安裝中斷造成，請先解決安裝錯誤。以上手動流程與新版啟動腳本使用相同短路徑，舊版 `start_windows.bat` 仍指向專案內 `.venv`，請使用上面的啟動命令或更新腳本。

## 快速製圖（v0.6.0）

1. 按「匯入圖片」，或使用它上方的「截圖匯入素材」。截圖時程式會暫時隱藏，拖曳框選螢幕範圍後自動加入素材；Esc 或右鍵取消。多螢幕各自顯示選取畫面，一次選取單一螢幕內的範圍，依該螢幕的像素密度擷取。截圖素材暫存於本次程式工作階段，關閉程式會清理暫存檔。
2. 如需取用素材的一部分，按「框選製圖範圍」。在原圖拖曳框選，框內拖曳移動、四角調整大小；「恢復整張」取消框選。每張素材各自記住本次使用的範圍，不修改原始檔。
3. 選模式；飽和度、明暗、上色、縮放與角度調整會自動更新預覽。無縫貼圖按「一鍵製圖」會以完整解析度暫存本輪結果，參數回到中性狀態，下一輪可繼續疊加。隨機變體按「儲存變更」則保留結果，切換到無縫貼圖繼續編輯。
4. 用 1／2／3／4／5 重複預覽檢查接縫，**存檔也依這個數量鋪排**：選 2 存 2×2 共四張素材，選 3 存 3×3 共九張；每張素材保留所選解析度。「全屏」將貼圖連續鋪滿上方檢視區，可拖曳平移、滾輪縮放；存檔仍依數量選單，不截取視窗大小或無限畫布。框選範圍時暫時顯示單張原圖。
5. 按匯入圖片下方的「儲存檔案」。原始檔存在時會詢問「是否覆蓋原檔案？」：選「覆蓋原檔」保留原檔格式，選「另存 JPEG」開啟另存視窗，或按「取消」。截圖素材、原檔已不存在或原格式無法寫入時，直接開啟 JPEG 另存視窗。

儲存會依目前設定重新計算完整解析度，不會拿小尺寸預覽圖代替。「單張素材大小」決定一張的解析度，再依預覽數量相乘；例如單張 1024×512、預覽 3，輸出為 3072×1536。覆蓋原檔也採相同鋪排規則。JPEG 採 quality 95、4:4:4 色彩取樣與 sRGB profile。覆蓋支援 JPEG／PNG／TIFF／BMP；先在同目錄完成圖片寫入與解碼檢查，再替換原檔。若運算期間原檔在外部變更，會停止覆蓋並顯示錯誤。

重複輸出直接鋪排 8-bit 圖塊，避免建立巨大的浮點數畫布。鋪排後上限為 1.6 億像素；超出時會提示降低單張大小或預覽數量，不會靜默縮小存檔。

調整與預覽不修改來源，只有確認「覆蓋原檔」才會寫入。覆蓋後，本次工作階段仍保留目前編輯基底，避免重複套用明暗或縮放；移除並重新匯入會讀取已儲存的新檔。「回到上次結果」只還原程式內的結果，若要更新磁碟檔案，需再次儲存。覆蓋使用 RGB 8-bit 工作流程，不保留多頁 TIFF、原始 EXIF 或其他來源中繼資料。

去暗角下方依序提供：

| 控制 | 用途 |
| --- | --- |
| 飽和度 | 0–200%，100% 原始飽和度，0% 灰階 |
| 明暗度 | −100–100%，0% 原始明暗，向右變亮、向左變暗 |
| 上色／恢復原色 | 開啟顏色視窗，用選定顏色取代原色並保留紋理明暗；恢復原色會清除上色，保留其他滑桿設定 |
| 素材縮放 | 25–400%，100% 原始大小；200% 讓紋路放大兩倍，輸出像素尺寸保持不變 |
| 旋轉角度 | −180–180°，繞單張素材中心旋轉；木地板先處理每張素材，再組合排列，板縫與地板排列不隨紋路旋轉 |

所有滑桿的預設點統一在中央，原有數值範圍保留，左右兩半各自對應預設值以下／以上的範圍。數值欄使用相同固定寬度，避免百分比或角度字數不同造成滑軌、藍色滑塊無法垂直對齊。按滑鼠右鍵恢復預設值：去陰影 85%、飽和度 100%、明暗 0%、素材縮放 100%、角度 0°、X／Y 隨機位移各 20%。筆刷與 BUMP 滑桿同樣支援中央預設與右鍵重設。

圖形介面已移除「輸出 JPEG 圖片」「輸出全部」「儲存專案」「開啟專案」「原圖比較」「接縫線」「查看結果」。儲存統一使用「儲存檔案」；隨機模式一次顯示一張結果，按「換一組」更換。命令列的進階批次／JSON 記錄不受桌面介面簡化影響。

| 模式 | 其他主要調整 |
| --- | --- |
| 無縫貼圖 | 去暗角／陰影、輸出大小 |
| 隨機變體 | 橫向／縱向張數、X／Y 隨機位移、素材縮放、旋轉、保留木紋方向、單張素材大小 |
| 木地板 | 去暗角／陰影、排列方式、板寬、板長、板縫、輸出大小 |
| 建立 BUMP | 開啟獨立視窗，調整明暗、對比，生成黑白 BUMP 或法線貼圖 |

### 隨機交錯與接續編輯

X／Y 滑桿控制每張素材各自隨機左右／上下移動的最大幅度。0% 不位移，100% 最多移動一張素材的寬／高；拖曳滑桿維持同一組隨機方向，只有按「換一組變體」才重新排列。素材接合處使用窄範圍融合並補齊，沒有透明空洞。隨機模式不顯示去陰影、飽和度、明暗、素材顏色及變化程度；色彩與陰影沿用無縫貼圖的調整，不再額外隨機改色。

隨機排列預設為 **2×2 共四份**；橫向、縱向張數分別可設 1–8，進入隨機模式時預覽先回到 1，避免一開始重複過多。每份保留所選像素尺寸，整張寬高按張數增加。例如 800×600 的素材，預設產生 1600×1200 的隨機單元；改成橫向 3、縱向 1，則產生 2400×600。只有互動預覽會配合視窗縮小顯示，狀態列會標示份數與完整排列像素；儲存變更及存檔重新計算完整解析度。若鋪排後超過上限，會提示減少預覽數量或手動選較小的素材尺寸，不會默默降低像素。

隨機位移對齊素材的完整像素，減少小數像素插值造成的柔化；只在接合處做窄範圍融合。寬幅排列以區塊繪製，避免超過 OpenCV 單次取樣的寬度限制。

「保留木紋方向」勾選時，隨機旋轉只使用 0°／180°，維持木紋走向；取消後也允許 90°／270°。矩形素材轉 90° 時，寬高會正確交換，保留像素比例。圖片檔仍有固定重複週期，重複預覽會鋪排同一個單元。

「儲存變更」會以完整解析度將目前隨機結果當作新編輯基底，轉到無縫貼圖；已套用的明暗、上色、縮放等控制歸為中性設定，避免效果再套用一次。這只保留本次程式工作階段的結果，不寫入原檔；關閉前請使用「儲存檔案」。

無縫貼圖的「一鍵製圖」也會保留本輪影像，讓下次調整疊加在已完成的圖上。套用後去陰影回到 0、明暗 0、飽和度 100%、縮放 100%、角度 0°並清除上色選擇；這些設定已包含在影像內，下一輪不會自動重複。裁切也會成為新素材大小，解析度選單回到自動並沿用已完成的像素尺寸。暫存只在本次工作階段，存成圖片仍按「儲存檔案」。

無縫貼圖的「一鍵製圖」下方提供「回到原圖」，清除目前素材的裁切、色彩、幾何、隨機結果、筆刷修補與復原歷史，回到本次匯入時的原圖和像素尺寸。去陰影設為 0、其他影像調整歸中性、預覽回到 1，確保立即存檔也保留原圖內容。即使本次工作階段已覆蓋過來源檔，仍可從記憶體還原匯入時的圖；按鈕不改寫磁碟，若要還原檔案需再按「儲存檔案」。移除後重新匯入會以新讀取的檔案作為原圖。

### 印章與明暗筆刷

貼圖視窗上方提供「印章畫筆」與「明暗筆刷」。開啟時先以所選完整解析度製作目前結果，作為新的編輯基底；已完成的調整會保留在圖內。筆刷啟用期間，右側製圖參數暫停操作；再按一次筆刷按鈕離開，即可繼續調整。

- 印章：Alt＋點擊選取參考點，或先按「選取參考點」再點圖面，接著拖曳塗抹。採對齊取樣，每筆開始時固定取樣影像，避免複製到自己剛畫過的內容。
- 明暗：選「刷亮」或「刷暗」，直接拖曳修改局部。以曝光增減保留紋理與 RGB 比例；亮部限制增益，避免色彩被裁切。
- 大小 1–512 px（預設 64 px，實際直徑最多為素材短邊），透明度 0–100%（預設 50%）。同一筆重複經過不會累加超過設定透明度，另畫一筆可以繼續加強。
- 筆觸跨四邊自動環繞，所有重複預覽與全屏鋪滿同步更新。「復原上一筆」可取消最近一筆；中鍵拖曳平移，滾輪縮放。
- 印章與明暗筆刷只顯示白色圓圈游標，不顯示十字或參考點十字；Alt 取樣仍正常運作。

修補保留在目前素材的編輯基底，離開筆刷或後續調整、存檔不會遺失。離開筆刷後清除單筆復原紀錄；寫入圖片仍使用左側「儲存檔案」。

### 獨立 BUMP／法線

製圖模式選「建立 BUMP」，會以目前貼圖的完整解析度開啟獨立視窗，主視窗保留原模式與彩色結果。調整 BUMP 明暗、對比；「黑白反轉」可反轉黑白，再按一次恢復。按「生成法線貼圖」可調整法線強度，使用目前 BUMP（包含黑白反轉）計算；按「返回 BUMP」切回黑白圖。法線使用週期取樣計算邊界，格式為 OpenGL +Y。

視窗下方「儲存檔案」預設另存 `原檔名_BUMP.jpg` 或 `原檔名_NORMAL.png`，不覆蓋素材。BUMP 為灰階 JPEG；法線為無損 RGB PNG，兩者均不附 sRGB ICC，應作為 linear／non-color 資料圖使用。存檔會按當時設定重新計算完整解析度，並依此獨立視窗的預覽數量鋪排；不使用縮小的預覽圖。這些圖由 RGB 明暗推估，仍須依材質目視調整。

其他數值自動計算。隨機模式按「換一組」換結果。拖曳控制時使用最長邊 1024 的背景預覽並合併連續變更；輸出會重新計算完整解析度，等待中的預覽不會覆蓋最新設定。去陰影／來源無變更時重用預處理素材，避免每次拉滑桿都重算大圖光照。可用「回到上次結果」還原上一次影像與調整設定。

「自動」使用選取範圍的解析度；木地板自動輸出為 1K。1K–8K 指長邊，短邊依比例計算，不強制拉伸成正方形。木地板預設整面為四片板長 × 十二列板寬，自動符合直鋪、固定錯縫與隨機錯縫的週期。

去暗角預設 85%，0 為停用，使用穩健光照曲面與紋理保護濾波。v0.5 改為兩輪校正，第二輪重新估計殘留陰影；保留增益上限與亮部保護，不直接將單輪曝光倍增。天然深色紋路與光照無法從單張 RGB 完美區分，仍應目視檢查；可框選排除照片過暗、遮擋或背景區域。縮小／旋轉以週期取樣處理空白區，並重建輸出邊界，不會增加黑角。

圖片依 EXIF 校正方向，有 ICC 時轉換為 sRGB；目前使用 RGB 8-bit 工作流程。木地板素材以保留比例的中心裁切符合板片，不直接拉伸。板縫寬設為 0 可輸出無板縫版本；Base Color 不加入假倒角光影。

## 命令列與架構

```sh
python -m texture_studio.cli tile 木紋.jpg --output output/tile --maps
python -m texture_studio.cli variants 木紋.jpg --output output/variants --count 8 --seed 42
python -m texture_studio.cli boards 板1.png 板2.png --config boards.json --output output/floor --maps
```

CLI 拒絕覆寫既有輸出。`boards.json` 是 `BoardSettings` 欄位物件，例如：

```json
{
  "width": 4096, "height": 2048,
  "world_width_mm": 3600, "world_height_mm": 1800,
  "board_width_mm": 150, "board_length_mm": 900,
  "pattern": "random", "gap_mm": 2, "periodic": true,
  "weights": [1, 2]
}
```

- `core.py`：讀寫、色彩管理、低頻光照估計、週期性 Poisson 分解、接縫量測。
- `variants.py`：可重現變體、週期取樣旋轉。
- `boards.py`：物理尺寸拼板、週期排列、板縫與倒角參考。
- `maps.py`：高度、粗糙度、OpenGL +Y 法線推估。
- `storage.py`：確認覆蓋後的暫存寫入、檔案變更檢查與原檔替換。
- `painting.py`：跨邊界印章、刷亮／刷暗與單筆透明度。
- `bump.py`、`bump_ui.py`：獨立 BUMP 與法線製作。
- `widgets.py`：共用預覽、中央預設滑桿與可取消工作執行緒。
- `ui.py`：介面與工作執行緒；`cli.py`：無 GUI 批次處理。

## 色彩與影像處理限制

Base Color 附 sRGB profile；Mask／Height／Roughness／Normal 不附 sRGB profile，在 Corona／3ds Max 中應設定 linear／non-color。Normal 需配合材質的法線方向設定。高度、粗糙度、法線僅為 RGB 推估，不能恢復量測的反射率或幾何。

週期性 Poisson 分解移除造成邊界跳變的平滑分量，不在中央做交叉羽化；但不是高階內容感知合成，也不保證所有天然紋理無可見重複。明暗與材質固有深色無法單從 RGB 完美區分，務必目視檢查。首末像素是相隔一個取樣點的相鄰像素，差值通常不是零。
