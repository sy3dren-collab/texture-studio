# Texture Studio — 智慧無縫貼圖與板材生成器
## Codex 專案開發規格書 v1.0

### 一、專案目標

開發一套 Windows 10 / 11 可獨立執行的桌面應用程式。

使用者可以拖入一張或多張圖片，透過自動化影像處理，產生適合 3ds Max 2025 與 Corona Renderer 使用的高品質材質貼圖。

**核心目標：**
1. 自動產生真正四方連續的無縫貼圖。
2. 自動校正圖片偏光、暗角、局部陰影及明暗不均。
3. 自動產生旋轉、翻轉及紋理變化版本。
4. 匯入多張單片木地板圖片，自動生成完整地板排列貼圖。
5. 可以調整板材排列方式、尺寸、間距及隨機程度。
6. 即時預覽效果並輸出高解析度圖片。
7. 全部本機運算，無須 API Key、雲端服務或網路連線。

---

### 二、開發技術規格

| 項目 | 規格 |
|---|---|
| 作業系統 | Windows 10 / 11 64-bit |
| 開發語言 | Python 3.11+ |
| 圖形介面 | PySide6 |
| 影像處理 | OpenCV、NumPy、Pillow |
| 高階影像處理 | scikit-image（視需要） |
| 打包方式 | PyInstaller |
| 支援格式 | JPG、PNG、TIFF、BMP |
| 輸出解析度 | 1K、2K、4K、8K、自訂 |
| 儲存設定 | JSON 專案檔 |
| API | 不使用外部 API |

程式架構必須模組化，避免 UI 與影像處理邏輯混在一起。

所有高耗時計算使用背景工作執行緒，確保介面不凍結，並提供進度顯示及取消操作。

# 三、核心功能模組

## 模組 A：四方無縫貼圖生成

### A01. 圖片匯入
- 支援拖放圖片。
- 支援瀏覽檔案。
- 支援多張圖片匯入。
- 自動讀取原始解析度。
- 支援中文檔名及路徑。
- 預設保留原圖比例及色彩資訊。

### A02. 自動無縫化
- 自動處理上下邊界。
- 自動處理左右邊界。
- 處理四個角落的連續性。
- 透過週期性邊界重建及紋理感知融合，減少明顯接縫。
- 避免單純羽化造成的中央模糊。
- 優先保留原始紋理細節。

可調參數：
- 接縫融合強度：0～100。
- 融合範圍：0～50%。
- 紋理保留強度：0～100。
- 自動 / 手動處理模式。

### A03. 光照與明暗校正

此功能列為核心重點。

需要處理：
- 左亮右暗。
- 上亮下暗。
- 四角暗角。
- 大範圍亮度漸層。
- 局部偏光與色偏。
- 重複貼圖時的格子狀暗部。

處理方式：
- 估算低頻光照分布。
- 使用多尺度光照校正。
- 分離大面積光照差異與局部真實紋理。
- 優先保留材質本身的明暗與顏色。

可調參數：
- 自動均勻化開關。
- 校正強度：0～100。
- 校正範圍。
- 色偏校正。
- 原始對比保留程度。
- 原始紋理保留程度。

不得將天然深色木紋或大理石紋路全部視為陰影消除。

### A04. 重複紋理預覽
- 1×1 原圖模式。
- 2×2 重複模式。
- 3×3 重複模式。
- 5×5 重複模式。
- 支援滑鼠滾輪縮放。
- 支援滑鼠拖動畫面。
- 支援原圖與處理結果比較。
- 可顯示及隱藏接縫輔助線。

### A05. 接縫品質檢測
- 計算上下邊緣差異。
- 計算左右邊緣差異。
- 偵測大範圍亮度差。
- 顯示接縫檢測結果。
- 提供視覺化接縫差異圖。

接縫數值只能作為輔助，不能直接代表整體紋理自然程度。

## 模組 B：隨機貼圖變體生成

### B01. 旋轉功能
- 0°。
- 90°。
- 180°。
- 270°。
- 可選擇任意角度旋轉。

任意角度旋轉必須使用週期性取樣或重新無縫化，確保輸出結果仍可四方連續。

### B02. 翻轉功能
- 水平翻轉。
- 垂直翻轉。
- 水平加垂直翻轉。
- 可設定是否允許鏡像。

### B03. 隨機變化
- 隨機方向。
- 隨機色相。
- 隨機亮度。
- 隨機飽和度。
- 隨機對比。
- 隨機平移偏移。

所有隨機項目均可獨立開關與調整強度。

### B04. 材質方向保護

提供兩種模式：

**自由模式**
- 適合石材、雲紋、抽象材質。
- 允許所有旋轉與翻轉。

**方向保護模式**
- 適合木紋、布料、直線紋理。
- 預設僅允許 0°、180°。
- 避免破壞原始紋理走向。

### B05. 批次生成變體
- 可設定輸出 2～50 張。
- 使用隨機種子 Seed。
- 相同 Seed 必須產生相同結果。
- 可單獨預覽各變體。
- 可選擇輸出指定變體。

注意：單純旋轉、翻轉及色彩變化，不等於產生全新紋理。後續可以擴充紋理重組功能，減少重複特徵。

## 模組 C：自動木地板及板材拼貼生成器

這是另一個獨立的核心模組。

使用者匯入多張單片板材圖片，程式自動按照指定排列規則生成完整貼圖。

### C01. 多張素材匯入
- 可一次匯入多張單片木板圖。
- 顯示素材縮圖。
- 可刪除、替換素材。
- 自動偵測圖片方向。
- 可指定木紋長度方向。
- 可手動設定素材權重。
- 可設定是否允許重複使用同張素材。

### C02. 單片素材預處理
- 裁切多餘背景。
- 旋轉校正。
- 尺寸標準化。
- 明暗校正。
- 色調統一。
- 保留各片木板的自然差異。
- 必要時進行板片延伸或裁切。

禁止未經設定就將所有木板強制拉伸到相同長寬比。

### C03. 板材排列模式

<escape>排列方式如下：</escape>

1. 直鋪排列。
2. 1/2 錯縫排列。
3. 1/3 錯縫排列。
4. 1/4 錯縫排列。
5. 隨機錯縫排列。
6. 隨機長短板排列。
7. 人字拼 Herringbone。
8. 魚骨拼 Chevron。
9. 籃編拼 Basketweave。
10. 自訂錯縫比例。

第一階段優先完成直鋪、固定錯縫與隨機錯縫；特殊拼法分階段開發。

### C04. 板材尺寸設定
- 木板寬度（mm）。
- 木板長度（mm）。
- 最小板長（mm）。
- 最大板長（mm）。
- 板縫寬度（mm）。
- 板材長寬比例。
- 整面地板寬度與長度。
- 圖片像素與實際尺寸換算。

### C05. 隨機分布設定
- 素材隨機權重。
- 隨機排列 Seed。
- 避免相鄰使用相同素材。
- 降低重複花紋集中出現的機率。
- 隨機旋轉 180°。
- 隨機翻轉。
- 隨機亮度。
- 隨機色差。
- 最短錯縫距離。
- 限制連續短板的數量。

### C06. 板縫與倒角
- 板縫寬度。
- 板縫顏色。
- 板邊倒角寬度。
- 倒角深度參數。
- 可選擇輸出無板縫版本。
- 可獨立輸出板縫遮罩。

Base Color 預設不繪製假的光照陰影。板縫深度及倒角效果優先透過 Height / Bump 貼圖表現，避免與 Corona 實際光照衝突。

### C07. 排列預覽
- 即時查看整面木地板。
- 可以放大檢查單片木板。
- 可顯示板片分界線。
- 更換 Seed 即重新排列。
- 可鎖定排列結果再修改顏色。
- 可調整整面地板的長寬比例。

### C08. 完整拼板貼圖無縫化
- 可啟用四方連續輸出模式。
- 左右邊界板材與排列必須相容。
- 上下邊界板材與排列必須相容。
- 板縫位置不能產生錯位。
- 保留原本排列規則。

需要採用週期性排列演算法，而不是將完成的木地板直接做一般影像羽化。

對於無法在指定尺寸內形成週期的排法，應提供調整尺寸或輸出非週期性貼圖的選項，不可宣稱已完成無縫處理。

# 四、輸出功能

### D01. 材質貼圖輸出

基本支援：

- Base Color。
- 板縫 Mask。
- Height / Bump 參考圖。
- Roughness 參考圖（進階）。
- Normal Map（進階）。

**限制：** 如果輸入只有一般 RGB 圖片，Height、Roughness、Normal 只能產生推估結果，並非量測得到的真實材質資訊。

### D02. 解析度
- 1024×1024。
- 2048×2048。
- 4096×4096。
- 8192×8192。
- 自訂長寬。

拼板模式應支援非正方形輸出。

### D03. 輸出格式
- JPG。
- PNG。
- TIFF。

預設 Base Color 使用 sRGB 色彩空間，資料型貼圖按照用途設定適當色彩管理。

### D04. 匯出設定
- 自訂輸出資料夾。
- 自動命名。
- 批次輸出。
- 保留實際材質尺寸資訊。
- 匯出設定 JSON。
- 保存所有隨機 Seed。

### D05. 3ds Max / Corona 支援
- 輸出圖片可直接用於 Corona Physical Material。
- 產生材質尺寸及 UV 比例資訊。
- 可選擇輸出板材素材組合。
- 後續擴充 CoronaMultiMap 輔助設定。

不將 CoronaMultiMap、CoronaTileMap 或 3ds Max 外掛整合作為第一版必要條件。

# 六、開發階段與優先順序

## Phase 1：無縫貼圖核心（P0）
1. 完成 Windows 圖形介面。
2. 完成單張圖片匯入。
3. 完成自動光照均勻化。
4. 完成四方無縫處理。
5. 完成 3×3 重複預覽。
6. 完成 PNG / JPG 輸出。
7. 完成原圖對比。

**驗收條件：**
- 可以正常處理木紋、石材、布料測試圖。
- 四個邊界可連續。
- 沒有明顯的中央羽化模糊。
- 明暗校正後，重複預覽不應出現明顯亮暗格子。
- 不破壞重要天然紋理。

## Phase 2：隨機變體（P1）
1. 加入旋轉。
2. 加入翻轉。
3. 加入色差。
4. 加入亮度變化。
5. 加入批次輸出。
6. 加入 Seed 設定。
7. 驗證變體的無縫性。

**驗收條件：**
- 相同 Seed 結果一致。
- 各變體可獨立輸出。
- 旋轉翻轉後仍符合所選無縫條件。

## Phase 3：木地板生成（P1）
1. 多張木板匯入。
2. 板材尺寸設定。
3. 直鋪。
4. 固定比例錯縫。
5. 隨機錯縫。
6. 隨機長短板。
7. 自動素材分配。
8. 板縫設定。
9. 大面積預覽。
10. 週期性拼板輸出。

**驗收條件：**
- 板材尺寸比例正確。
- 不會出現不合理的短板。
- 同一素材不會過度集中。
- 隨機結果可重現。
- 支援 4K 輸出。
- 宣稱無縫的排列，其板縫與影像紋理均必須跨邊界連續。

## Phase 4：進階拼法（P2）
1. Herringbone。

4. 自訂排列。
5. 板片局部手動替換。

## Phase 5：Corona 進階材質（P2）

# 七、程式品質要求

1. 不得直接覆蓋原始素材。
2. 操作須支援復原或重新產生。
3. 所有參數可以儲存及重新載入。
4. 處理 4K / 8K 圖片時須控制記憶體用量。
5. 不可因圖片格式不支援就讓整個程式當機。
6. 長時間處理時顯示進度。
7. 支援中英文檔名與資料夾。
8. 圖形介面使用繁體中文。
9. 所有影像演算法必須具備獨立測試。
10. 將輸入檔案、參數、Seed、程式版本記錄在專案設定中。
11. 專案原始碼使用 GitHub 版本管理。
12. 每個階段完成後建立可執行測試版本。

# 八、Codex 開發執行指令

請使用本規格書建立 Texture Studio 專案。

執行原則：

1. 先建立完整程式架構與目錄。
2. 根據 Phase 1～5 逐階段開發。
3. 優先完成可靠的影像處理核心。
4. 所有影像處理功能要能單獨測試，不得依賴 UI。
5. 先建立自動測試，再整合到 Windows 介面。
6. 完成一個階段後執行測試並留下紀錄。
7. 不可用假按鈕、靜態圖片或模擬結果代替真實功能。
8. 發生錯誤時先分析原因、修正，再重新測試。
9. 每次修改保留 Git 提交紀錄。
10. 提供 requirements.txt、README.md、啟動批次檔及 PyInstaller 打包腳本。
11. 提供可在 Windows 執行的打包方式；若目前環境無法產生 Windows EXE，應明確告知，不可假稱已完成。
12. Phase 1 驗收通過後才進入 Phase 2，依此類推。

**最終交付內容：**
- 完整 Python 專案。
- Windows 圖形介面。
- 實際可運作的影像處理模組。
- 自動化測試。
- Windows EXE 打包腳本。
- 繁體中文使用說明。
- 各階段測試與修改紀錄。

優先目標是功能正確、貼圖品質與穩定性，不是單純追求介面美觀。
